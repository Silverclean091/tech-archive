# Focus & Grass 설계 스펙

작성일: 2026-10-13

## 1. 목적과 범위

오늘의 할 일을 체크리스트로 기록하고, 날짜별 달성 현황을 GitHub 잔디 같은 히트맵으로 보여주며, 집중 시간 관리를 위한 포모도로 타이머를 함께 제공하는 개인용 웹앱.

### 확정된 결정

| 항목 | 결정 |
|---|---|
| 형태 | 브라우저에서 실행하는 웹앱 (바닐라 HTML/CSS/JS, 빌드 도구 없음) |
| 저장 | `localStorage` (백엔드·계정 없음, 단일 사용자) |
| 히트맵 기준 | 그날의 완료율 (완료 ÷ 전체 할 일) |
| 포모도로와 할 일 | 독립 (연결하지 않음) |
| 지난 할 일 | 날짜별 완전 분리, 이월 없음. 지난 날짜는 열람·수정 가능 |
| 타이머 복원 | 새로고침/탭 종료 시 복원하지 않고 리셋 |
| 타이머 종료 알림 | 소리 + 브라우저 알림. 알림 권한이 없거나 소리가 꺼져 있어도 알 수 있게 탭 제목에도 종료 안내를 남긴다 |
| 여러 탭 | 같은 브라우저의 여러 탭이 같은 데이터를 공유한다. 한 탭의 변경은 다른 탭에 반영되고, 서로를 덮어쓰지 않는다 |
| 입력 방식 | 마우스 사용을 전제로 한다. 키보드 전용 탐색(히트맵 방향키 이동 등)은 지원하지 않는다 |
| 실행 방법 | 브라우저가 `file://` 페이지의 ES 모듈을 막으므로 로컬 서버가 필요하다. Node 서버 하나(`serve.js`)를 macOS·Windows·Linux가 공통으로 쓰고, `run.sh`(macOS/Linux/Git Bash)와 `run.bat`(Windows)이 그것을 실행하는 얇은 래퍼다. 서버는 `127.0.0.1`에만 열고 앱 파일(`index.html`, `css/`, `js/`, `tests/browser/`)만 내보낸다. 빌드는 필요 없다 |

### 범위 밖 (YAGNI)

- 다기기 동기화, 로그인, 서버
- 할 일의 포모도로 연결, 미완료 이월
- 포모도로 횟수의 히트맵 반영
- 진행 중 타이머 복원, 탭 간 타이머 공유 (저장 데이터만 공유하고 타이머는 탭마다 독립)
- 히트맵 키보드 이동(roving tabindex), 요일·월 라벨, 다크 모드

## 2. 화면 구성

한 페이지에 세 영역을 둔다.

```
┌──────────────────────────────────────────────┐
│  🍅 Focus & Grass                            │
├──────────────────────────────────────────────┤
│  [히트맵]  최근 53주 × 7요일, 칸 = 하루         │
│   범례: 적음 ▢▤▥▦▣ 많음                       │
│   칸 hover: "10/12 · 3/4 완료 (75%)"          │
├───────────────────────┬──────────────────────┤
│  [체크리스트]           │  [포모도로]            │
│  📅 2026-10-13 (오늘)   │      25:00           │
│  ☑ 보고서 쓰기          │  [시작] [일시정지] [리셋]│
│  ☐ 운동                │  집중 25분 / 휴식 5분   │
│  [+ 할 일 추가]         │  ⚙ 시간 설정           │
│  진행률 1/2 (50%)       │  오늘 완료한 🍅: 2      │
└───────────────────────┴──────────────────────┘
```

### 히트맵
- 최근 53주 × 7요일 격자. 칸 하나가 하루.
- 색은 5단계: 0% / ~25% / ~50% / ~75% / 100%. 할 일이 없는 날은 가장 옅은 회색(0% 단계와 구분되는 "기록 없음" 색).
- 칸 클릭 시 체크리스트가 해당 날짜로 전환된다. hover 시 날짜·완료 수·완료율 툴팁.
- 미래 날짜 칸은 선택할 수 없다.
- 칸 버튼은 한 번만 만들고 이후에는 속성만 갱신한다(다시 만들면 누르던 칸이 교체되어 클릭이 유실된다).
- 앱을 켜 둔 채 자정이 지나면(1초 간격으로 확인), 오늘을 보고 있던 화면은 새 오늘로 따라가고 과거 날짜를 보고 있던 화면은 그대로 둔다.

### 체크리스트
- 선택된 날짜(기본: 오늘)의 항목을 추가, 체크, 제목 수정, 삭제할 수 있다. 제목 수정은 항목을 더블클릭해 입력창으로 바꾸고, Enter로 확정, Esc로 취소하며, 입력창을 벗어나면(blur) 확정한다. 한글 등 조합 입력 중의 Enter/Esc는 글자 확정용이므로 편집을 확정·취소하지 않는다.
- 지난 날짜도 동일하게 수정 가능하다. 미래 날짜는 열 수 없다.
- 다른 날짜를 보고 있을 때 "오늘로" 버튼을 표시한다.
- 하단에 진행률(완료/전체, %)을 표시한다.
- 빈 문자열(공백뿐인 입력 포함)은 추가하지 않는다. 제목은 최대 200자(문자 단위, 이모지가 반으로 잘리지 않는다)이고, 화면에는 글자 그대로(HTML로 해석하지 않고) 보여 준다.
- 항목 행은 렌더링 사이에 재사용한다. 편집 중에 타이머 종료·설정 저장 등으로 화면이 다시 그려져도 편집창과 입력 내용이 유지되고, 편집을 확정한 직후의 다른 버튼 클릭이 유실되지 않는다. 편집 중에 다른 날짜로 이동하면 그 편집은 버린다(다른 날짜에 쓰이지 않도록).

### 포모도로 패널
- 체크리스트와 독립적으로 동작한다.
- 남은 시간, 시작/일시정지/리셋 버튼, 현재 설정 요약, 설정 패널, "오늘 완료한 🍅" 카운트를 표시한다. 카운트는 히트맵에 반영하지 않는다.
- 시작·일시정지·재개 버튼은 더블클릭의 두 번째 클릭을 무시한다(같은 자리에 나타난 다음 버튼이 그 클릭을 받아 의도와 다르게 일시정지되는 것을 막는다).

## 3. 데이터 구조

`localStorage` 키 2개. 모든 저장 객체에 `version` 필드를 둔다.

```js
// "ffg:todos"
{
  "version": 1,
  "days": {
    "2026-10-13": [
      { "id": "k3x9a", "text": "보고서 쓰기", "done": true },
      { "id": "m2p4q", "text": "운동",       "done": false }
    ]
  }
}

// "ffg:settings"
{
  "version": 1,
  "focusMin": 25,
  "breakMin": 5,
  "autoSwitch": false,
  "soundOn": true,
  "notifyOn": true,
  "pomodoroCount": { "2026-10-13": 2 }
}
```

- 날짜 키는 UTC가 아닌 **로컬 날짜** `YYYY-MM-DD`. 자정 전후 하루 어긋남을 막는다.
- 비어 있는 날은 키를 만들지 않는다. 마지막 항목을 삭제하면 키도 지운다.
- 항목 `id`는 날짜 내에서 고유하면 된다. 저장소에서 읽을 때 같은 날짜 안의 중복 id에는 새 id를 주고(항목은 모두 보존), 공백뿐인 제목의 항목은 버린다.
- `pomodoroCount`의 날짜는 세션이 끝났어야 하는 시각의 로컬 날짜다. 탭이 절전이어서 처리가 늦어도 늦게 처리된 날이 아니라 끝난 날에 센다.
- 저장소에서 읽은 값은 항상 검증·정규화한다(모양이 틀린 항목, 범위를 벗어난 설정값은 기본값으로 대체).

### 경계 원칙
- 순수 로직(`dateUtils`, `todos`, `settings`, `pomodoro`)은 DOM·`localStorage`를 모른다.
- `ui/`는 렌더링과 입력만 담당하고 규칙을 갖지 않는다.
- `localStorage` 접근은 `storage.js`만 한다.
- 레벨 계산(완료율 → 0~4단계)은 `heatmap.js` 안의 순수 함수로 두어 테스트한다.
- 브라우저 API(Web Audio, Notification)는 `notify.js`만 감싼다. 알림 생성이 예외를 던져도 앱은 멈추지 않는다.

## 5. 포모도로 타이머

### 상태 머신

```
        start                 시간 만료
 idle ────────▶ focus ─────────────────▶ break ──만료──▶ idle
  ▲               │ ▲                      │ ▲
  │         pause │ │ resume         pause │ │ resume
  │               ▼ │                      ▼ │
  │             paused(focus)            paused(break)
  └───────────── reset (어느 상태에서든) ───────┘
```

- **idle**: 대기. 설정된 집중 시간(기본 25:00)을 표시한다.
- **focus 만료**: 🍅 카운트 +1 후 break로 전환한다.
  - `autoSwitch` 꺼짐: break를 대기 상태로 두고 "휴식 시작" 버튼을 눌러야 시작한다.
  - `autoSwitch` 켜짐: break가 즉시 시작된다.
- **break 만료**: idle로 돌아간다. 다음 집중은 항상 직접 시작한다.
- **reset**: 어느 상태에서든 idle로 돌아가며, 진행 중이던 집중은 🍅로 세지 않는다.
- **집중 중 설정 변경**: 진행 중인 세션에는 적용하지 않고 다음 세션부터 적용한다.

### 시간 계산
- 시작 시 `endAt = now + 남은시간`을 저장하고, 250ms마다 `남은시간 = endAt - now`로 화면을 갱신한다. `setInterval` 감소 방식은 쓰지 않는다(백그라운드 탭에서 느려짐).
- 숨겨진 탭에서는 브라우저가 주기 타이머를 1분에 한 번 수준으로 늦출 수 있으므로, 세션 시작·재개 시 종료 시각에 맞춘 단발 `setTimeout`을 함께 건다. 종료 처리와 알림이 늦지 않게 하기 위함이다.
- 일시정지 시 남은 시간만 저장하고, 재개 시 `endAt`을 재계산한다.
- 상태 머신은 `now`를 인자로 받는 순수 함수로 구현해 가짜 시계로 테스트한다. 종료 처리는 끝난 세션이 끝났어야 하는 시각(`endedAt`)을 함께 알려, 🍅를 그 시각의 날짜에 센다.
- 타이머 화면은 250ms마다 갱신되지만 값이 바뀐 곳만 DOM에 쓴다(대기·일시정지 중에는 쓰기 없음).

### 알림
- **소리**: Web Audio API로 짧은 비프음 생성(외부 파일 없음). 집중 종료와 휴식 종료의 음이 다르다. 사용자 클릭(시작 버튼) 시점에 오디오 컨텍스트를 준비한다.
- **브라우저 알림**: 처음 "시작" 클릭 시 권한 요청. 거부되면(또는 브라우저가 알림 생성을 막으면) 소리와 탭 제목 변경으로 대체한다.
- **탭 제목**: 실행 중 `🍅 24:13 · Focus & Grass`(휴식은 `☕`) 형태로 남은 시간을 표시한다. 세션이 끝나면 `✅ 집중 끝! · Focus & Grass` / `✅ 휴식 끝! · Focus & Grass`를 남기고, 다음 시작·리셋·탭 복귀 시 지운다.

### 설정
- 집중 분(정수 1~120), 휴식 분(정수 1~60), 자동 전환, 소리 on/off, 알림 on/off.
- 시간 입력은 앞뒤 공백을 뺀 숫자(0-9)만 인정한다. 빈 칸, 글자, 소수, `1e1`·`0x10`·`+5` 같은 형식, 범위를 벗어난 값은 저장하지 않고 입력 칸 아래에 오류를 표시하며 이전 값을 유지한다.
- 저장되면 입력 칸을 실제 저장된 값으로 되돌려 채운다(예: ` 7 ` → `7`). 설정은 "저장"을 눌러야 적용된다.

## 6. 에러 처리

- `localStorage` 사용 불가 또는 용량 초과: 메모리에만 저장하고 "저장되지 않습니다" 배너를 표시한다. 저장소는 읽기만 확인해서 고르므로, 가득 차서 쓰기가 실패해도 기존 기록은 계속 읽힌다. 이후 저장이 성공하면 배너는 사라진다.
- 저장된 JSON이 손상된 경우(깨진 JSON, `null`, 배열, 숫자 등 모양이 틀린 값 포함): 해당 부분만 버리고 빈 값/기본값으로 복구하며 앱은 계속 동작한다.
- 설정값 범위 검증은 입력 단계에서 수행한다.
- 여러 탭: 다른 탭이 저장소를 바꾸면(`storage` 이벤트) 이 탭의 메모리 사본을 버리고 다시 읽어 화면에 반영한다. 반영하지 않으면 이 탭의 다음 저장이 다른 탭의 내용을 덮어쓴다.

## 7. 테스트

순수 모듈은 Node 내장 러너(`node --test`)로 단위 테스트하고(의존성 설치 없음), 화면(DOM) 동작은 브라우저에서 여는 테스트 페이지(`tests/browser/`)로 검증한다. 소리·실제 브라우저 알림·한글 입력기(IME)의 실제 조합 동작은 자동 검증하지 못하므로 수동으로 확인한다.

**단위 테스트**
- `dateUtils`: 로컬 날짜 키 변환, 자정 경계, 53주 칸 배열(요일 정렬, 미래 칸 처리), 선택 가능 판별, 자정 이동 규칙.
- `todos`: 추가/토글/수정/삭제, 빈·공백 문자열 거부, 긴 글 제한(이모지 포함), 마지막 항목 삭제 시 날짜 키 제거, `completionRate`(0개일 때 포함).
- `settings`: 기본값, 시간 입력 검증(빈 칸, 글자, 0, 소수, 범위 초과, 지수·16진수 형식, 공백 허용).
- `storage`: 손상·모양이 틀린 데이터 복구, 공백 항목·중복 id 정리, 저장소 쓰기 실패 시 메모리 폴백, 가득 찬 저장소에서의 읽기, 저장 성공 시 배너 회복, 다른 탭 변경 반영(`invalidate`).
- 히트맵 레벨: 경계값(0, 25, 50, 75, 100%)과 "기록 없음", 툴팁 문구.
- `pomodoro`:
  - idle에서 start하면 focus로 가고 만료 시각을 정확히 계산한다.
  - pause 후 resume하면 남은 시간이 보존된다.
  - focus 만료 시 카운트 +1, break 전환 (`autoSwitch` 켜짐/꺼짐 각각).
  - reset은 카운트를 증가시키지 않는다.
  - 만료 시각을 한참 지난 뒤 틱이 들어와도(탭 절전 후) 전환은 한 번만 일어나고 카운트가 중복되지 않으며, 끝난 시각(`endedAt`)이 정확히 보고된다.
  - 종료까지 남은 시간, 탭 제목 문구(실행 중, 종료 안내, 일시정지).
- `notify`: 알림 생성이 예외를 던져도 `false`를 반환한다(스텁 사용).
- `serve`: 요청 경로 해석(`/`→`index.html`, 쿼리 무시), 경로 이탈(`..`, 인코딩·역슬래시·NUL·`//` 변형) 거부, 앱 파일 외(`package.json`, `serve.js`, 문서, 단위 테스트, 숨김 파일) 비노출, 올바른 MIME, 실제 서버에 대한 200/404/405(GET/HEAD만 허용).

**브라우저 테스트 페이지** (`tests/browser/ui-smoke.html`, `timer-smoke.html`)
- 체크리스트·히트맵: 편집 중 전체 렌더에도 편집창 유지, 편집 확정 후 다른 컨트롤 노드 유지, 날짜 전환 중 편집 처리, 조합 입력 중 Enter 무시, 진행률·히트맵 레벨 갱신.
- 다중 탭: 두 번째 탭의 변경이 첫 번째 탭에 반영되고 서로를 덮어쓰지 않는다.
- 더블클릭: 시작 후 두 번째 클릭이 일시정지를 누르지 않는다.
- 설정: 저장 후 입력 칸 보정, 잘못된 형식 거부. 대기 중에는 DOM 쓰기가 없다. 자정을 넘기면 오늘 화면이 새 날짜로 넘어간다.
- 타이머(실제 시간 약 4분): 1분 집중/휴식 사이클, 자동 전환 켬/끔, 일시정지·재개·리셋, 종료 안내가 탭 제목에 나타나고 시작·리셋 시 지워진다.
- 이 페이지들은 앱의 `localStorage`(`ffg:*`)를 비우고 테스트하므로, 시작할 때 백업했다가 끝나면 복원한다. 저장소는 서버 주소(호스트+포트) 단위이므로 실제로 쓰는 주소와 다른 포트로 서버를 띄워 연다.
