# TaskFlow MVP 기능 기획서

- 문서 유형: 기능 기획서
- 작성자: 김도윤(PM), 이서연(디자인 리드)
- 작성일: 2026-03-18
- 관련 문서: 2026-03-05_킥오프_회의록.md, 2026-04-02_디자인리뷰_회의록.md

## 목적
TaskFlow MVP(v1.0)에 포함될 4개 핵심 기능의 범위와 요구사항을 정의한다. 본 문서는 개발/디자인/QA 전 조직이 공통으로 참고하는 기준 문서다.

## 타겟 사용자
- 주 타겟: "파워유저" — 하루 평균 5개 이상 프로젝트를 동시에 관리하는 스타트업/중소규모 팀 실무자
- 부 타겟: 팀 리더 및 프로젝트 매니저 (캘린더 동기화 기능의 관리자 뷰 활용)

## 핵심 기능 (MVP 범위)

### 1. 할일관리
- 할일 생성/수정/삭제/완료 처리 (CRUD)
- 마감일, 담당자, 우선순위(상/중/하) 지정
- 리스트뷰 기반 UI (Flow UI 디자인 시스템 적용)

### 2. 팀 캘린더 동기화
- 팀원 개개인의 할일 마감일을 하나의 캘린더 뷰로 통합
- 파워유저 그룹의 핵심 요구사항으로 최우선 개발 항목
- 외부 캘린더(Google Calendar) 연동은 v1.1로 연기

### 3. 협업 코멘트
- 개별 할일 항목에 팀원이 댓글을 남길 수 있는 기능
- 멘션(@) 기능 포함, 멘션 시 알림 발송 연동

### 4. 알림
- 마감일 임박, 담당자 지정, 코멘트 멘션 시 푸시 알림 발송
- FCM(Android), APNs(iOS) 기반 구현

## MVP 범위 제외 항목 (Out of Scope, v1.1 이후 검토)
- 파일 공유 기능
- 다크모드
- 외부 캘린더(Google Calendar 등) 연동

## 우선순위 및 개발 순서
1. 할일관리 (스프린트 1)
2. 팀 캘린더 동기화 (스프린트 2, 파워유저 핵심 요구사항으로 우선 배치)
3. 협업 코멘트 (스프린트 3)
4. 통합 테스트 및 안정화 (스프린트 4)

## 용어 정의
- **파워유저(Power User)**: 하루 평균 5개 이상의 프로젝트를 동시에 관리하는 TaskFlow 핵심 타겟 사용자군.
- **Flow UI**: TaskFlow 프로젝트의 사내 자체 디자인 시스템 명칭.
- **Out of Scope**: 현재 버전(MVP/v1.0)에서 의도적으로 제외하고 이후 버전에서 검토하기로 한 기능 범위.

## 참고
본 문서의 우선순위 및 범위 결정 배경은 raw/meetings 내 관련 회의록(킥오프, 디자인리뷰, 스프린트기획)을 참고.
