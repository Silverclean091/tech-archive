# MVP 범위 및 기술 스택 결정

## 결정 사항

### MVP 범위 (4개 핵심 기능)
- **할일관리**: 할일 생성/수정/삭제/완료 처리 (CRUD), 마감일/담당자/우선순위 지정
- **팀 캘린더 동기화**: 팀원 일정과 할일 마감일을 하나의 캘린더 뷰에서 통합
- **협업 코멘트**: 개별 할일에 팀원 댓글, 멘션(@) 기능 포함
- **알림**: 마감일 임박, 담당자 지정, 코멘트 멘션 시 푸시 알림 (FCM/APNs)

**제외 항목 (v2로 연기)**
- 파일 공유 기능

### 기술 스택
- **프론트엔드**: React Native (iOS/Android 동시 크로스플랫폼 개발)
- **백엔드**: Node.js + PostgreSQL (기존 사내 인프라 호환성)
- **알림 인프라**: FCM(Android) / APNs(iOS)

### 출시 계획
- **플랫폼**: iOS/Android 동시 출시
- **타겟 사용자**: 스타트업/중소규모 팀의 "파워유저" (하루 5개 이상 프로젝트 동시 관리)

## 배경
회사 내 협업 툴 혼용으로 인한 업무 효율 저하 문제 해결. 기존 외주 협업 툴 대비 알림/캘린더 동기화 강화로 차별화.

## 의사결정 프로세스
- 초기 논의: 파일 공유 포함 vs 제외 → 결과: v2로 연기 결정
- 기술 스택: React Native + Node.js 제안에 이견 없음
