# Flow UI 정의

## 정의
TaskFlow 프로젝트에서 사용하는 **사내 자체 디자인 시스템**의 명칭.
회사 최초의 통일된 디자인 시스템으로, 색상, 타이포그래피, 컴포넌트 가이드를 포함.

## 구성 요소
- 색상 팔레트
- 타이포그래피 스타일 (폰트, 크기, 두께)
- 컴포넌트 가이드 (버튼, 입력 필드, 카드 등)

## 설계 원칙
- **리스트뷰 중심**: 저밀도 레이아웃을 기본 원칙으로 함
- **재사용성**: 컴포넌트 재사용성을 높이기 위해 설계

## 의의
- 프로젝트명 "TaskFlow"와의 일관성
- 사내 디자인 시스템 구축의 첫 사례
- iOS/Android 크로스플랫폼 일관성 보장
