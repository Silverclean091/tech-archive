# TaskFlow 팀원 및 역할

## 핵심 팀 구성

### 💼 경영/기획 (Business)
- **김도윤** (PM, Project Manager)
  - 역할: 프로젝트 총괄, 주간 진행 상황 공유
  - 주요 담당: 로드맵 관리, 스프린트 기획, 출시 공지

### 🎨 디자인 (Design)
- **이서연** (디자인 리드)
  - 역할: 디자인 시스템 구축, 와이어프레임 설계, 온보딩 UX
  - 주요 성과: Flow UI 디자인 시스템 v0.1 작성

### 💻 개발 (Engineering)
- **박준혁** (개발 리드, Backend)
  - 역할: 전체 기술 아키텍처, 백엔드 개발, 알림 인프라
  - 주요 담당: 기술 스택 확정, 환경 세팅, 알림 인프라 재발 방지 체크리스트
  
- **최하늘** (iOS Developer)
  - 역할: iOS 플랫폼 개발
  - 주요 담당: 온보딩 플로우 화면 개발
  
- **정민재** (Android Developer)
  - 역할: Android 플랫폼 개발
  - 주요 담당: 팀 캘린더 동기화 API 설계, 캘린더 중복 버그 수정

### 🧪 품질보증 (QA)
- **한소율** (QA 리드)
  - 역할: 전체 QA 운영, 버그 관리, 출시 준비
  - 주요 담당: QA 전담 기간 가이드, 버그 재검증, 핫픽스 대응팀 운영

## 주간 미팅

- **요일**: 매주 목요일 10:00
- **참석자**: 전체 팀 (조직에 따라 변동 가능)
- **용도**: 스프린트 기획, 회고, 진행 상황 공유

## 의사결정 구조

| 영역 | 주도자 | 참여자 |
|---|---|---|
| MVP 범위 | 김도윤(PM) | 박준혁(Dev), 이서연(Design) |
| 기술 스택 | 박준혁(Dev Lead) | 최하늘(iOS), 정민재(Android) |
| 디자인 | 이서연(Design Lead) | 김도윤(PM), 박준혁(Dev) |
| 일정/로드맵 | 김도윤(PM) | 전체 팀 |
| QA/출시 | 한소율(QA Lead) | 박준혁(Dev), 전체 팀 |
