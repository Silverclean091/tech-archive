# 디자인 결정 기록

## 노션 스타일을 기준으로 삼은 이유
여러 화면에서 재사용할 수 있는 담백한 UI를 목표로 한다.
장식보다 정보 전달에 집중하는 스타일이라 어떤 주제에도 자연스럽게 어울린다.

## 단색 배경을 사용하는 이유
그라데이션은 화면마다 인상이 달라져 일관성을 해친다.
단색 배경과 구분선만으로 영역을 나누면 화면이 늘어나도 통일감이 유지된다.

## 그림자를 최소화하는 이유
그림자가 많으면 모든 요소가 떠 보여 위계가 흐려진다.
팝업처럼 실제로 화면 위에 떠 있는 요소에만 그림자를 사용해 의미를 분명히 한다.

## 색을 태그에만 사용하는 이유
색이 여러 곳에 쓰이면 어디가 중요한지 알기 어렵다.
기본 화면은 무채색으로 두고, 분류가 필요한 태그와 배지에만 색을 사용한다.

## CSS 변수만 사용하는 이유
값을 한 곳에서 관리해야 다른 화면에 재사용할 때 그대로 가져갈 수 있다.
